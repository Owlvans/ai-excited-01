"Eclipse Close-Up" — a front-facing owl with molten-gold eyes, a glowing full-moon eclipse ring right behind its head, deep teal night sky. One bold focal point that hits at thumbnail size. main.py copies the committed entry.png to the output directory, byte-identical on every run, no network.

## Run it

```sh
python3 main.py
```

Writes entry.png to $MAKEFUN_OUTPUT_DIR, or /output when that is unset.
